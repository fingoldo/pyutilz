# py-ci-shared is consumed as a git checkout (it is not published to PyPI). A PEP 440 direct
# reference ("name @ git+https://...") in project metadata makes the built distribution

# it silently -- so it must stay out of [project.optional-dependencies] entirely.
#
# Usage:  pip install -e ".[dev]" -r requirements-dev.txt

# (format_warn, black_filtered_apply, advisory_warn). py-ci-shared itself requires Python >=3.9;
# the marker keeps this file usable on a py3.8 interpreter, where those hooks are not needed.
